# متجر القبس — Al-Qabas Store

متجر إلكتروني كامل (واجهة زبون + لوحة تحكم أدمن) مبني خصيصاً لمتجر **القبس** لبيع الطابعات ومستلزماتها.
مبني بالكامل بالكود (Node.js + Express)، بدون الاعتماد على أي منصة SaaS جاهزة — يعني الملكية والتحكم الكامل لك 100%.

---

## 1) التشغيل محلياً (على جهازك)

يتطلب تثبيت [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).

```bash
cd al-qabas-store
npm install
npm start
```

بعدها افتح المتصفح على:

- **واجهة المتجر (الزبائن):** http://localhost:3000
- **لوحة التحكم (الأدمن):** http://localhost:3000/admin
  - اسم المستخدم: `admin`
  - كلمة المرور: `qabas2026`

  ⚠️ غيّر بيانات الدخول هذي قبل ما تنشر الموقع فعلياً — موجودة بملف `db.json` تحت مفتاح `admin`.

---

## 2) شنو مبني بالفعل (v1)

**واجهة المتجر:**
- الصفحة الرئيسية: بانر متحرك (Slider) + شريط فئات + شبكة منتجات
- فلترة حسب الفئة والبحث
- صفحة تفاصيل منتج + منتجات ذات صلة
- سلة مشتريات (تُحفظ بالمتصفح) + صفحة إتمام الطلب (Checkout)
- حساب رسوم التوصيل تلقائياً حسب عدد القطع

**لوحة التحكم:**
- تسجيل دخول بسيط
- نظرة عامة (عدد المنتجات، الطلبات، المبيعات، الزبائن)
- إدارة كاملة (إضافة / تعديل / حذف): المنتجات، الفئات، العلامات التجارية، واجهة التطبيق (البانرات)، الاشعارات
- إدارة الطلبات وتغيير حالتها (قيد الانتظار / تجهيز / تم الشحن / تم التوصيل / ملغي)
- عرض الزبائن (يُضافون تلقائياً عند إتمام أول طلب لهم)
- الإعدادات العامة (اسم المتجر، الهاتف، العنوان، رسوم الشحن)

**قاعدة البيانات:** ملف `db.json` بسيط (JSON) — سهل الفهم والتعديل، ومناسب كنسخة أولى (v1) للتجربة والعرض.

---

## 3) الصور

كل الصور حالياً عبارة عن بطاقات SVG مؤقتة (بألوان وأيقونات) بانتظار صورك الحقيقية.
لتغييرها: افتح لوحة التحكم → عدّل رابط الصورة لكل منتج/بانر/علامة تجارية، أو ارفع صورك إلى مجلد:

```
public/images/products/
public/images/banners/
public/images/brands/
```

واستخدم المسار مثل: `/images/products/my-photo.jpg`

---

## 4) قبل النشر الفعلي (Production) — مهم

هذا الإصدار (v1) جاهز للتجربة والعرض محلياً، لكن قبل ما تفتحه للزبائن الحقيقيين لازم:

1. **قاعدة بيانات حقيقية** — استبدال `db.json` بقاعدة بيانات فعلية (مثل PostgreSQL أو MongoDB) حتى تتحمل عدد كبير من الطلبات والمستخدمين بنفس الوقت.
2. **رفع صور حقيقي** — إضافة خاصية رفع الصور من لوحة التحكم مباشرة (حالياً تحتاج تحط رابط الصورة يدوياً).
3. **نظام دفع إلكتروني** — ربط بوابة دفع (زين كاش، ماستركارد، إلخ) إذا تريد دفع أونلاين، غير الدفع عند الاستلام.
4. **أمان تسجيل الدخول** — استبدال تسجيل الدخول البسيط الحالي بنظام مصادقة حقيقي (كلمات مرور مشفرة + جلسات آمنة).
5. **استضافة ودومين** — رفع المشروع على استضافة مثل Render أو Railway أو VPS، وربط دومين مثل alqabas.store.

أقدر أساعدك بأي وحدة من هذي الخطوات إذا حاب تكمل.

## 5) هيكلية المشروع

```
al-qabas-store/
├── server.js              # السيرفر (Express) + كل الـ API
├── db.json                 # قاعدة البيانات (منتجات، فئات، طلبات...)
├── package.json
└── public/
    ├── index.html           # الصفحة الرئيسية
    ├── product.html          # تفاصيل المنتج
    ├── cart.html             # السلة والدفع
    ├── css/style.css
    ├── js/ (common.js, store.js, product.js, cart.js)
    ├── images/ (شعار، بانرات، منتجات، علامات تجارية)
    └── admin/
        ├── index.html         # لوحة التحكم
        ├── css/admin.css
        └── js/admin.js
```
